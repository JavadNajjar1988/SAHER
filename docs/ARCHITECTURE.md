# معماری سیستم ساهر (SAHER System Architecture)

این سند معماری پیاده‌سازی‌شده در فاز ۱ و نقشهٔ راه کلان ماژولار ساهر را مشخص می‌کند.

## ۱. ساختار کلان (Modular Monolith)

```
├── apps/
│   └── web/                   # واسط کاربری فارسی (React 19 + TypeScript 5.7 + Vite 6)
│       ├── src/
│       │   ├── components/    # قطعات مشترک رابط کاربری (Sidebar, Preview, Detail, Import)
│       │   ├── services/      # کلاینت ارتباطی نوع‌داده‌دار با بک‌اند و لایه پایداری محلی
│       │   ├── types/         # تعاریف مدل‌های داده و DTO
│       │   └── main.tsx       # ریشهٔ برنامه و مدیریت وضعیت فضای کار
├── services/
│   ├── api/                   # وب‌سرویس سریع محلی (Python 3.10+ + FastAPI)
│   │   ├── config.py          # مدیریت تنظیمات و مسیرهای ذخیره‌سازی
│   │   ├── database.py        # اتصال و ایجاد پایگاه‌داده SQLite همراه با FTS5
│   │   ├── repository.py      # الگوی مخزن (Repository Pattern) برای داده‌های آرشیو
│   │   ├── schemas.py         # تعاریف استاندارد Pydantic
│   │   └── main.py            # اندپوینت‌های REST نسخه ۱ (/api/v1)
│   ├── ingestion/             # موتور استخراج محتوا و پردازش متنی اسناد
│   │   └── extractor.py       # استخراج متن از فایلهای PDF، DOCX، متنی و تشخیص متادیتا
│   └── intelligence/          # آداپتورهای هوش مصنوعی محلی (در حال توسعه)
├── tests/
│   └── test_api.py            # آزمون‌های خودکار یکپارچگی بک‌اند، پایداری و FTS5
├── data/                      # محل ذخیره‌سازی محلی پایگاه‌داده (saher.db) و فایل‌های آرشیو
└── docs/                      # مستندات تصمیم‌ها، معماری و وضعیت پروژه
```

## ۲. مشخصات پایگاه‌داده SQLite و FTS5
- پایگاه‌داده محلی SQLite با فعال‌بودن حالت WAL و کلیدهای خارجی (Foreign Keys)
- جدول جدول‌بندی جستجوی متنی فارسی و لاتین (`files_fts`) با استفاده از ماژول FTS5 و توکنایزر `unicode61`
- ایندکس‌های منحصر‌به‌فرد بر روی هش SHA-256 برای جلوگیری از تکرار فایل‌ها و حفظ یکپارچگی داده‌ها
- استخراج متن واقعی برای فرمت‌های متنی و اسناد اداری
