# ساهر

سامانهٔ آرشیو محلی فارسی با ذخیرهٔ واقعی فایل، استخراج متن، OCR، جست‌وجوی صفحه‌محور و صف پردازش پایدار.

## قابلیت‌های نسخهٔ عمومی آرشیو

گزارش هر سند در پنجرهٔ جزئیات، پنج تب دارد: «مشخصات سند»، «فراداده»، «متن و یادداشت بازبین»، «شواهد مستند» و «مجموعه‌ها و منابع». طراحی راست‌به‌چپ است و تب‌ها با کلیدهای جهت و Home/End قابل پیمایش‌اند.

در تب شواهد، نقل‌قول، شمارهٔ صفحه، منبع، یادداشت و وضعیت بازبینی را ثبت کنید. تطابق دقیق نقل‌قول با متن ذخیره‌شده مستقل از تأیید دستی بازبین محاسبه می‌شود؛ تطابق، تأیید انسانی یا اعتبار حقوقی نیست. پس از اصلاح متن صفحه، تطابق دوباره محاسبه می‌شود. هر سند تا ۱۰۰ شاهد دارد. ذخیرهٔ گزارش برای ثبت ویرایش‌ها و تهیهٔ Word به‌روز لازم است.

تب منابع، منابع و شمار شواهد سند جاری و تعداد اسناد و منابع اصلی هر پوشهٔ آرشیو را نشان می‌دهد؛ مجموعه‌ها صفحه‌بندی دارند. خروجی Word شامل مشخصات و متن کامل سند، یادداشت بازبین، همهٔ شواهد و وضعیت و مرجع آن‌ها و منابع همان سند است.

- شناسنامهٔ قابل‌ویرایش سند: پوشهٔ شخصی، شرح سوژهٔ سند، نوع فایل، برچسب مکان، مرجع منبع و یادداشت
- ورود پوشه همراه با زیرپوشه‌ها و حفظ مسیر آن‌ها در شناسنامه؛ خطای هر فایل به‌صورت جداگانه گزارش می‌شود
- پیشنهاد نوع تصویر بر اساس وجود فرادادهٔ دوربین یا نام نماگرفت، همراه با توضیح مبنا و امکان اصلاح دستی؛ در نبود شواهد، نوع تصویر نامشخص می‌ماند
- فیلتر هم‌زمان موضوع، پوشهٔ شخصی و نوع ثبت‌شده، همراه با صفحه‌بندی ۵۰تایی کتابخانه
- خروجی Word فارسی برای متن، PDF و تصاویر: شناسنامه، برچسب‌ها، SHA-256، متن خام یا اصلاح‌شدهٔ همهٔ صفحات، خطاها و اطمینان OCR
- حفظ متن خام در نمایش و خروجی؛ نرمال‌سازی فقط برای جست‌وجو انجام می‌شود. نویسه‌های کنترلی غیرمجاز XML در Word حذف می‌شوند
- تمدید اجارهٔ کار حین پردازش، محدودیت زمان فراخوانی OCR و بررسی مهلت کار در مرز مراحل

این امکانات برای توصیف اسناد هستند. هیچ دادهٔ حقوقی مرجعی به این نسخه افزوده نشده و تعیین اتهام یا صحت حقوقی انجام نمی‌شود. تحلیل تصویری قدیمی مبتنی بر قواعد است، نه مدل بینایی معنایی.

در جزئیات فایل، بخش «شناسنامهٔ سند» را تکمیل و ذخیره کنید؛ سپس «خروجی Word» را بزنید. فیلتر نوع فقط نوع تأیید و ذخیره‌شده در شناسنامه را اعمال می‌کند. فیلتر پوشه نام کامل پوشه را تطبیق می‌دهد و فایل‌های روی دیسک را جابه‌جا نمی‌کند.

## اجرا

برای اجرای رابط، سرویس و کارگر پردازش با داکر، در ریشهٔ مخزن اجرا کنید.

```sh
docker compose up -d --build
```

رابط روی نشانی محلی زیر در دسترس است. فایل‌های آرشیو و پایگاه‌داده در حجم پایدار داکر ذخیره می‌شوند.

```text
http://127.0.0.1:8730/
```

## اجرای محلی برای توسعه

Python 3.10+ و Node.js 22+ لازم است. برای OCR باید Tesseract 5 در PATH و مدل‌های `fas.traineddata` و `eng.traineddata` نصب باشند. مسیر مدل‌ها با `SAHER_OCR_MODEL_DIR` تعیین می‌شود. نصب اولیه به اینترنت نیاز دارد؛ پردازش فایل و OCR پس از نصب محلی است.

در ویندوز و پوشهٔ اصلی مخزن:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e '.[dev]'
npm ci
npm run dev
```

برای اجرای رابط تنها در محیط توسعه:

```sh
npm install
npm run dev:web
```

نشانی محلی در خروجی فرمان اجرا نمایش داده می‌شود. برای ساخت نسخهٔ اجرایی از فرمان زیر استفاده کنید.

```sh
npm run build
```

فایل قفل وابستگی‌ها در مخزن ثبت شده است. برای نصب دقیق نسخه‌های ثبت‌شده می‌توانید از فرمان زیر استفاده کنید.

```sh
npm ci
```

کد رابط در پوشهٔ زیر قرار دارد.

```text
apps/web
```

برای محیط‌هایی که فقط یک برنامه را وارد می‌کنند، می‌توان همین پوشه را به‌عنوان ریشهٔ برنامه انتخاب کرد. فایل تنظیمات بسته‌ها در ریشهٔ مخزن نیز اجرای برنامه را از طریق فضای کاری فراهم می‌کند.

## قابلیت‌های کتابخانه

- کتابخانه با نمای کارتی و فهرستی، جست‌وجو و فیلتر نوع فایل
- جزئیات فایل، اصلاح موضوع، افزودن و حذف برچسب و تأیید بازبینی
- ورود واقعی فایل، اعتبارسنجی، تشخیص فایل تکراری و ذخیرهٔ پایدار
- طراحی راست‌به‌چپ و چیدمان سازگار با نمایشگر کوچک
- فونت وزیرمتن همراه برنامه، با مجوز موجود در پوشهٔ فونت‌ها

حالت نمایشی از آرشیو اصلی جداست و فقط با انتخاب صریح فعال می‌شود. فایل‌ها و اصلاحات در حالت متصل پایدار هستند. پشتیبان‌گیری موجود مربوط به مهاجرت رکوردهای نمونهٔ قدیمی است و جایگزین پشتیبان کامل آرشیو نیست. جست‌وجوی معنایی و بستهٔ دسکتاپ Electron هنوز پیاده‌سازی نشده‌اند.

## آزمون و محدودیت‌ها

```sh
python -m pytest tests/test_api.py tests/test_worker_and_jobs.py tests/test_document_card.py -q
npm run test:web
npm run build
npm audit
```

آزمون‌های `tests/test_milestone3_ocr.py` به موتور و مدل‌های واقعی OCR نیاز دارند. بدون آن‌ها شکست این آزمون‌ها طبیعی است. دقت کامل OCR تضمین نمی‌شود؛ متن قابل بازبینی و اصلاح است. فونت Word به نام Vazirmatn تنظیم شده است؛ برای ظاهر یکسان، نسخهٔ دسکتاپ این فونت را روی دستگاه بازکنندهٔ سند نصب کنید.

مهلت کل کار در مرز مراحل کنترل می‌شود و OCR زمان‌انتظار مستقل دارد. عملیات بومی غیرقابل‌قطع مانند استخراج PDF درون همان فراخوانی قابل توقف اجباری نیستند؛ تا بازگشت عملیات، اجاره تمدید می‌شود. ساخت و اجرای Docker باید روی دستگاهی با موتور فعال Docker آزموده شود.

## خطای نصب در استودیوی گوگل

پیام عمومی شکست نصب به‌تنهایی علت را مشخص نمی‌کند. فایل تنظیمات بسته‌ها و گزارش کامل نصب برای تشخیص دقیق لازم است. این نمونه دارای نسخه‌های مشخص وابستگی‌ها و فایل قفل است و نصب و ساخت آن در محیط محلی بررسی شده است.
